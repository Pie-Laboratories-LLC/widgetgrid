# Life of Pie

This video faithfully describes the inspiration behind the name Pie
Laboratories.  In fact, I think I was imagining this video before the name had
even come to me.

[![Pie Laboratories, LLC](./pie-laboratories-llc.png)](https://youtu.be/xyrcQJLn53s)

Produced using the methodology described within.

I commissioned the corporate logo - the pie in the laboratory - on Upwork.  My
goal was to render it in my application, Anonyme, with some light animation
effects.  I was finally able to achieve that.

Previously I've written about my SVG Parser, which I've used to build the user
interface for Anonyme described in a previous post and video.  Since that was
all I needed it for, it only supported the SVG elements commonly used in
OT-SVG fonts.

The corporate logo proved considerably more work for the SVG Parser, but that
was completed for this video: support for embedded PNG images, CSS styles,
polygon and polyline, and opacity / masks.  I'd also previously released text
support that was incomplete; it wasn't actually parsing the text and tspans
under the text node, which is tantamount to making buildings without doors.
That has been fixed.  Expect a new release of the SVG Parser with these changes
soon.

Finally, I've noted before that my preferred way to work with Claude was
through the browser.  The writing has been on the wall for some time.  It's a
tedious process, and it frequently feels like I'm reverse-centauring,
particularly on large projects with lots of fiddly details.  Using the browser
method, I wrote the Kubernetes operator and kitten sidecar in a day.  Claude
Code produced the rendering of the corporate logo and text in a couple of
hours.

That leaves me a little melancholy, as I do enjoy the act of programming.  It's
gratifying to write a text / tspan parser for SVG.  But I just can't compete
with Claude Code, and I have bigger fish to fry.  So I guess I'm all in.
